## How to run it

1. Open the project in INtelliJ
2. Run 'App.java'
3. Type menu selection on home screen
3. i) "N" Type the information for the new workout
3. ii) "W" Takes user to the View Workouts screen
3. iii) "X" Exit the program
4. On the View Workouts screen type menu selection
4. i) "A" View all workouts
4. ii) "Q" view quick workouts (30 minutes or less)
4. iii) "F" view favorite workouts
4. iv) "S" search workouts
4. v) "H" return to the home screen
